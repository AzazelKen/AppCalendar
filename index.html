Persistencia de Datos, Cloud Sync & GitHub Pages

Archivo de datos con autoguardado

Vincula un archivo .json de tu PC: cada cambio (cuentas, usuarios, DJs, grupos, eventos, géneros…) se escribe solo en ese archivo, organizado por secciones. Para cargarlo en otro PC o navegador, usa «Abrir archivo existente».

Sin archivo vinculado

Tu navegador no permite escribir archivos automáticamente (usa Chrome o Edge en PC para el autoguardado). Aquí «Guardar ahora» descarga el archivo y «Abrir archivo existente» lo carga.

Secciones del archivo: usuarios · grupos · djs · eventos · generos · actividad · ajustes. Incluye las contraseñas de las cuentas: guarda el archivo en un lugar privado.

Copia de seguridad manual (descargar / importar JSON)

3. Cómo subir esta App a GitHub Pages en 1 minuto

  1. Descarga este archivo HTML y renómbralo a index.html (el logo oficial de ECLION ya va incrustado dentro del propio archivo para que no se rompa nunca).
  2. Crea un repositorio en GitHub y sube el archivo index.html.
  3. Ve a Settings → Pages en tu repositorio, selecciona la rama main y guarda. ¡Tu web de ECLION estará online!
